NFC & diagnostic · Android

NFC Card Emulator

Labo de test NFC HCE ISO-DEP sur Android. Outil de test et d'analyse NFC : émulation HCE ISO-DEP (APDU), gestion de profils de cartes et import de dumps MIFARE Classic pour comparaison et diagnostic.

Dernière versionCode source

Fonctionnalités

  • Profils de cartes : ajout, sélection, sauvegarde / restauration JSON
  • Import de dumps VIGIK JSON, Proxmark3 et .dump bruts
  • Émulation HCE ISO-DEP : SELECT AID, GET UID, READ
  • Protocole de démonstration AES-GCM + scripts PC/SC (lecteur ACR122U)
  • Journal intégré : copie, export

Outil de test pour des systèmes que vous contrôlez. Il ne clone pas les badges VIGIK (MIFARE Classic / Crypto-1).
