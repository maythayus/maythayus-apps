Paris sportifs · PC (Windows / Linux)

Bet.Bot

L'analyse de paris sportifs qui croise quatre sources. Pipeline local qui croise les probabilités Forebet, les statistiques Flashscore, un modèle de Poisson maison et les cotes Unibet, puis fait commenter les écarts par un LLM local (LM Studio). Tourne sous Windows comme sous Linux.

Dernière versionCode source

Fonctionnalités

  • Quatre sources croisées pour chaque match pariable
  • Modèle de Poisson : matrice des scores exacts, marchés cohérents entre eux
  • LLM local au choix (MiMo-7B-RL par défaut) : rien ne sort de votre machine
  • Fonctionne sous Windows et sous Linux (Omarchy)
  • Rapport Markdown prêt à lire
